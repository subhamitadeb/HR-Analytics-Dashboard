# HR-Analytics-Dashboard
Power BI HR Analytics Dashboard to analyze employee attrition.

## Project Overview
This project is a Power BI dashboard to analyze employee attrition in a company.

## Key Insights
- Highest attrition in 26-35 age group
- Employees with salary upto 5k have highest attrition
- Laboratory Technician role has highest attrition

## Tools Used
- Power BI
- Data Visualization

## Files
- HR Dashboard.pbix
- Dashboard Image.png

## Purpose
To understand employee attrition patterns and help companies take better decisions.
